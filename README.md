# Kelime Oyunu (Word Game) -Mobil Projem 🚀

Merhaba! Bu proje, mobil uygulama geliştirme dünyasına attığım ilk adım ve benim **ilk Android / Mobil projem**. Mobil teknolojilere ve uygulama geliştirmeye olan yoğun ilgim doğrultusunda, kendimi geliştirmek ve pratik yapmak amacıyla bu kelime oyununu geliştirdim. 

Bu süreçte karşılaştığım problemleri çözmek, yeni mimariler öğrenmek ve kullanıcı deneyimini (UX/UI) tasarlamak benim için harika bir deneyim oldu. Geliştirmeye ve yeni şeyler öğrenmeye olan tutkumla bu alanda daha derinleşmeyi hedefliyorum.

## 🎮 Proje Hakkında

Bu uygulama, kullanıcıların harf gridleri üzerinden kelimeler türeterek puan kazandığı, çeşitli animasyonlar ve bonus mekanikleri (patlatma vb.) barındıran eğlenceli bir kelime oyunudur.

Kullanıcı etkileşimlerini hem "sürükle-seç" (drag-to-select) hem de "dokun-seç" (tap-to-select) mekanikleriyle destekleyerek modern ve akıcı bir oyun deneyimi sunmayı amaçladım.

## 🛠️ Kullanılan Teknolojiler ve Teknik Altyapı

Bu projeyi geliştirirken güncel mobil geliştirme teknolojilerini ve tasarım kalıplarını kullandım:

*   **Framework:** [Flutter](https://flutter.dev/) - Çapraz platform desteği ve hızlı UI geliştirme yeteneği için tercih ettim.
*   **Dil:** [Dart](https://dart.dev/)
*   **Durum Yönetimi (State Management):** `Provider` - Oyun içi mantığın (harf seçimi, puanlama, can/süre durumu vb.) ve UI güncellemelerinin birbirinden ayrı, temiz bir şekilde yönetilmesi için kullanıldı.
*   **Veri Kalıcılığı (Local Storage):** `shared_preferences` - Oyuncunun en yüksek skorları, kalan bonusları ve oyun ilerlemesinin cihaz üzerinde güvenli bir şekilde saklanması sağlandı.
*   **Animasyonlar:** Flutter'ın yerleşik animasyon kütüphaneleri kullanılarak harflerin düşüşü (yerçekimi etkisi), bonus kullanım efektleri ve UI geçişleri (parlama/neon efektleri tasarımı) yapıldı.
*   **Oyun Mantığı:** Grid üzerinde yol bulma (pathfinding), geçerli kelime kontrolü (validation) ve çapraz kaydırma sırasında oluşan hataların giderilmesi gibi algoritmalar implemente edildi.

## 🚀 Kurulum ve Çalıştırma

Projeyi kendi bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1.  Flutter SDK'sının bilgisayarınızda kurulu olduğundan emin olun.
2.  Projeyi klonlayın:
    ```bash
    git clone https://github.com/yalives7/WORD-GAME.git
    ```
3.  Proje dizinine gidin ve bağımlılıkları yükleyin:
    ```bash
    cd WORD-GAME
    flutter pub get
    ```
4.  Uygulamayı bir emülatörde veya fiziksel cihazda başlatın:
    ```bash
    flutter run
    ```
